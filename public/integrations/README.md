# Integration Assets

Store integration logos and icons here.

## File naming convention:

### Icons (for cards, large display)
- `{integration}-icon.svg` or `.png`
- Recommended size: 64x64px or larger
- Examples: `braze-icon.svg`, `klaviyo-icon.svg`

### Favicons (for tables, small display)
- `{integration}-favicon.svg` or `.png`
- Recommended size: 16x16px or 32x32px
- Examples: `braze-favicon.svg`, `klaviyo-favicon.svg`

## Where to get logos:

1. **Official brand assets** - Check integration's brand/press kit
2. **SVG format preferred** - Scales better, smaller file size
3. **Transparent background** - Works with light/dark themes
